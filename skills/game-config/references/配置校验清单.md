# 配置校验清单

按实际变更选择相关项，不要求每次全部执行。

## 源文件

- 格式、语法和编码可解析；
- 必填字段、类型和空值语义正确；
- 主键、联合键和唯一索引无冲突；
- 单位、范围、枚举、概率和集合结构符合约定。

## 引用与资源

- 跨表、跨文件和父子引用存在；
- 列表之间的数量、顺序或键值对齐；
- 资源路径、Prefab、图标、脚本或外部 ID 存在；
- 删除或重命名不会留下悬空引用。

## Schema

- 新字段或类型的默认值和兼容策略清楚；
- 引用、索引、输出范围和校验声明正确；
- 客户端、服务端或工具所需类型代码同步生成；
- 旧数据或旧配置仍可加载，或已有迁移方案。

## 生成

- 执行项目标准命令，不手改生成物；
- 生成成功且退出状态可信；
- 生成物 diff 只包含预期对象和目标；
- 只改数据时没有无理由的大量代码 diff；
- 必要时再次生成，确认无新的非确定性 diff。

## 输出与加载

- 各目标端包含应有数据，不包含不应暴露字段；
- 服务端或消费工具能够加载；
- 缺失或错误配置能给出可定位错误；
- 仍需运行时代码接线时明确标为“待代码接入”。

## 记录

主文档只写执行项、结果、失败原因和剩余风险。完整命令输出与日志保留原位置并给出路径。
