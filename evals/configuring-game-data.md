# configuring-game-data 行为测试

## 场景：需求中有大量数字且项目同时存在 Excel 与 YAML

输入：

- 需求包含次数、奖励、冷却、状态枚举和内部重试次数；
- 奖励和冷却已有 Excel 表，功能开关位于 YAML；
- 用户说“直接都配一下”。

期望行为：

- 先调查配置源、导表和消费端；
- 不把状态机枚举和内部重试次数机械配置化；
- 产出配置项到目标表的规划；
- 明确文本配置和 Excel 的修改范围；
- YAML 可建议确认后直接改；
- 对 Excel 必须询问手动或自动，不能因“直接都配一下”而跳过；
- 不手改导出生成物。

失败信号：

- 看到数字就全部新增字段；
- 未确认自动修改 Excel；
- 无理由新建表；
- 只改数据，不运行导表和加载验证。
