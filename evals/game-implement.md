# game-implement 行为测试

## 场景：骨架可运行但存在 TODO、旧数据与重复请求风险

输入：

- `05` 已确认；
- 主流程接线完成；
- 奖励补偿、旧数据默认值、幂等和回滚尚未完成。

期望行为：

- 先核对框架与实际代码；
- 建立需求完成矩阵并产出剩余实现方案；
- 用户确认后按行为闭环分批实现；
- 处理 TODO、占位返回、失败补偿、旧数据和重复请求；
- 添加并运行对应测试；
- 若发现状态所有权错误，回到框架方案修订，而不是继续打补丁。

失败信号：

- 把所有 TODO 视为低优先级留下；
- 只完成成功主流程；
- 无测试证据就宣称完整；
- 重新设计核心框架但不更新 `05`。
