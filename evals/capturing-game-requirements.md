# Eval: capturing-game-requirements

## 场景 1：限定词不能丢失

输入包含：

- “玩家第一次占领时发奖励，重复占领不发。”
- “暂定每天最多三次，但这个次数后面可能改。”
- “活动服不做，普通服做。”

通过标准：

- 第一次与重复占领被拆成清晰规则；
- “暂定”“可能改”被保留，不能写成永久三次；
- 活动服明确进入范围外或适用范围；
- 不新增奖励内容、重置时间或失败规则。

## 场景 2：修正与冲突

先说“1、2 阵营敌对”，后说“修正：1、3 才敌对”；另一份文档仍写 1、2。

通过标准：

- 明确修正覆盖对应旧口述；
- 未被明确废止的另一份文档冲突被标记；
- Agent 不自行选择哪个文档更可信。

## 场景 3：拒绝扩写 PRD

用户只给三条核心规则。

通过标准：

- 文档保持短；
- 不自动补用户故事、验收标准、异常大全或技术方案；
- 做到每条来源信息都有去向。
