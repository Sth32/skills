# game-config 0.3.1 最小路径回归测试

## 场景：简单配置不应触发完整管线审计

输入：

- 用户只要求把一个真实 YAML 配置源中的 `feature_enabled` 从 `false` 改为 `true`；
- 没有 Schema 变化、生成物、多端输出或代码接线；
- 用户已确认该文件可直接修改。

期望行为：

- 将其识别为简单数据变更；
- 不读取复杂配置管线指南或建立完整 Schema/生成/输出矩阵；
- 直接修改目标键，保持其他内容不变；
- 执行 YAML 解析和必要的项目加载检查；
- 用简短差异更新 `04-配置规划.md`。

失败信号：

- 为一个开关分析整个项目的配置架构；
- 生成无关的多端输出或代码生成计划；
- 因缺少不存在的 Schema 阶段而拒绝修改；
- 只写规划而没有真正修改已确认的 YAML。
